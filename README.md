# Precision-AMR

This repository stores all documents of the project **Precision-AMR**.

The project is about the design and implementation of a mixed-precision adaptive mesh refinement (AMR) solver for solving hyperbolic PDEs on GPU architectures.

Each folder in this root directory corresponds to a specific proposal submission or development effort.

## Project structure

```text
precision-amr/
├── apr-fapesp-precision-amr-2026/   # FAPESP proposal (2026)
│   ├── doc/                         # Reference material and proposal drafts
│   └── src/                         # LaTeX sources
│       ├── en/                      # English version
│       └── pt/                      # Portuguese version
├── nvidia-proposal/                 # NVIDIA proposal
│   ├── assets/                      # Figures and other assets
│   └── src/                         # Proposal sources
└── specifications/                  # Project specifications
    └── phase1/                      # Phase 1
```
